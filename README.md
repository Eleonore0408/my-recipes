# My Recipes

Site de recettes de cuisine réalisé en HTML, dans le cadre de ma formation.
Il comporte une page d'accueil qui renvoie vers trois pages de recettes : crêpes, cookies et tiramisu.

## Compétences mises en pratique

- Structure d'une page HTML (boilerplate)
- Titres, paragraphes, listes ordonnées et non ordonnées
- Insertion d'images avec texte alternatif
- Liens relatifs entre les pages
- Utilisation de la ligne de commande (cd, ls, mkdir, touch)
- Utilisation de Git en ligne de commande via SSH (clone, add, commit, push)
- Mise en ligne du site avec GitHub Pages
